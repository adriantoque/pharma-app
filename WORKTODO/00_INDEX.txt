--------------------------------------------------------------------------------
CONVENTIONS - every task honours these
--------------------------------------------------------------------------------
C1  Branch order in app_router.dart MUST equal destination order in
    app_shell.dart. `StatefulNavigationShell.goBranch` takes an index, not a
    route name, so a wrong order does not throw -- it silently shows the wrong
    screen while the bar highlights a different one. This is the single
    coupling in the app that fails silently, and it is why task 04 exists.

C2  A tab's NavigationDestination label MUST equal that tab's AppBar title.
    Task 04 locates each tab's title by its bar label. A mismatch does not
    throw; it makes a title test find nothing.

C3  Tab roots centre their AppBar title. Pages pushed from a Home tile
    lead-align theirs. This is the existing app convention, and task 03 exists
    because four screens change sides of it.

C4  Home's marker in tests is `find.text('Expiring Meds')`. It used to be
    `find.text('Real Time Inventory')`, which the Inventory tile provided. Once
    that tile is gone the old marker finds nothing on Home.

C5  MedicineProvider reads only once `auth.user != null`
    (medicine_provider.dart:100-108). Sign in BEFORE constructing it or the
    catalogue never arrives and every test sees an empty price list. The
    constructor calls `_onAuthChanged()` immediately, so the order of
    `auth.login()` and `MedicineProvider(...)` is load-bearing.
